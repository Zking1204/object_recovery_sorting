# Skill card: pynq-overlay-load

- **Name**: `pynq-overlay-load`
- **Description**: 需要在 PYNQ 上加载或更换 overlay，或加载后画面、寄存器行为异常，要判断"是位流没烧进去，还是别的问题"时使用。本技能只做 overlay 加载与加载后校验，不做时序收敛与业务逻辑调试。
- **Scope**: 通用。换题目、换 PYNQ 板卡仍可用，不绑定本队题目。
- **已验证效果**: 加载后能可靠区分"位流未生效""频率不对""句柄没建起来"三类故障，而不是笼统地"跑不通"。
- **来源**: 多次上板联调中出现"屏幕全黑但 PS 侧 SCCB、VDMA 状态、寄存器回读全部正常"，最终靠加载自检定位到硬件描述文件里的 FCLK0 分频仍是 4/4，PL 实际只跑 62.5 MHz。
