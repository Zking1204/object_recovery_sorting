# Skill card: change-proposal

- **Name**: `change-proposal`
- **Description**: 准备改动一个已经上板验证通过的工程，需要先讲清改什么、影响谁、怎么回退时使用。
- **Scope**: 通用。
- **已验证效果**: 每次改动都有备份、影响面清单与回退路径，回退时不会凭记忆改回去。
- **来源**: 曾未经明确许可就动工程并触发整体回滚，此后固化为"报备不等于许可"：没听到明确的"做"就一个字都不动。
