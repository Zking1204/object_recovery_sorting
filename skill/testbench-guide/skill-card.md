# Skill card: testbench-guide

- **Name**: `testbench-guide`
- **Description**: 需要写或改 testbench，特别是要判断"测试失败到底是 DUT 错还是测试自己错"时使用。
- **Scope**: 通用。
- **已验证效果**: 测试台有明确判据、失败时打印期望值与实际值、能证明不是自证其说。
- **来源**: 曾为让测试变绿去改期望值，被识别为错误做法并整体回退，由此确立"改测试必须有独立证据"。
