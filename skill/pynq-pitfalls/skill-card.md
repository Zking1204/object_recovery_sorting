# Skill card: pynq-pitfalls

- **Name**: `pynq-pitfalls`
- **Description**: 在 PYNQ 上遇到"PS 侧一切正常但画面不动""寄存器读回怪值""第一次能跑第二次不行"这类难以归因的现象时使用。
- **Scope**: 通用。
- **已验证效果**: 把常见故障按现象快速分流到根因，避免在错误的方向上反复试。
- **来源**: 由数十次上板排障归纳：加载 overlay 前访问 PL 地址会挂死 CPU；帧同步未开启会顿挫并重影；重复构造加速器句柄会泄漏 CMA 内存等。
