# Skill card: timing-report-reading

- **Name**: `timing-report-reading`
- **Description**: 时序不收敛，或需要判断"这条违例到底要不要修"时使用。
- **Scope**: 通用。
- **已验证效果**: 能分辨真违例与虚约束，并定位到是逻辑级数还是布线延迟。
- **来源**: 时钟跨到 MMCM 输出后，静态约束频率与运行时频率不一致，一度把虚约束当成真违例反复优化。
