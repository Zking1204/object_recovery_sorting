# Skill card: verification-methods

- **Name**: `verification-methods`
- **Description**: 需要为某个模块设计"怎么验"的方案，或怀疑现有验证其实没验到点上时使用。
- **Scope**: 通用。
- **已验证效果**: 每类模块都有匹配的判据：逐值比对、计数校验、时序窗口、上板寄存器回读。
- **来源**: 出现过"改期望值让测试变绿"的自证其说做法，改完仍不通过说明没找到真因，之后固化为禁止清单。
