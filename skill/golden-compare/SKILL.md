# 黄金参考比对

> **归属**：`pynq/` 通用 PYNQ 技能 ｜ 来源编号 **P6**（前半）
> **比赛点名方向**：「**黄金参考比对**、性能与资源数据自动采集并生成报告的工具」

---

## Purpose

**目的**：**用机械比对替代人眼判断** —— 每次改动之后，自动回答"画面/数据有没有变"。

**预期产出**：

| 产出 | 说明 |
|---|---|
| 一套黄金参考 | 每类检查点存一份 `.npy`（+ 可选 PNG 便于肉眼看） |
| 一个比对函数 | 返回 `(是否通过, 最大差, 平均差, 差异像素占比)` |
| 一个指纹函数 | 只要"变没变"时的轻量判据 |

**前置条件**：能取到帧（见 `../pynq-dma-cache/SKILL.md`），且**参数组一致**。

---

## When to Use

- 每次改动之后，需要回答"**这次改动有没有把画面/数据弄坏**"的场合
- 建立了新基线（比如刚上板跑通）想留个基准
- 想用**结构性判据**代替人眼看图

## When NOT to Use

- **画面本身在变**（摄像头对着动的场景）时，逐像素比对不适用 ⇒ 改用结构性判据
  （如"画面的平均亮度在合理区间"）
- 黄金参考必须**在同一组参数**（分辨率、窗口、曝光模式）下采集，否则比对无意义
- 想知道"为什么变了" —— 本技能只告诉你"变了"

---

## DO's

- 每类检查点**都存一份黄金参考**（`.npy` 用于比对，PNG 用于肉眼看）
- 比对**给容差**（图像链路上允许 ±2 的灰度噪声波动）
- 用**差异像素占比**而不是"有没有差异"来判定（少量噪声不该判失败）
- 需要"变没变"时用**指纹**（取画面底部若干行，抗噪且敏感）
- **机械比对永远优于人眼判断**

## DON'Ts

- **不要整幅取指纹** —— 在多缓冲环形搬运下会**饱和**（每个采样都在变），失去判别力
- **不要拿不同参数组下的帧互相比**
- **不要在画面本身在动的时候用逐像素比对**

## Workflow

### Step 1：建立黄金参考

```python
import numpy as np
from PIL import Image

def save_golden(img, path):
    """把当前这一帧存成黄金参考"""
    Image.fromarray(img).save(path)
    np.save(path + '.npy', img)
    print("黄金参考已存:", path, img.shape)
```

### Step 2：比对（两种粒度，按需要选）

```python
def compare_golden(img, golden_path, atol=2):
    """
    与黄金参考比对。
    atol : 允许的逐像素灰度差（图像链路上允许 ±2 的噪声波动）
    返回 (是否通过, 最大差, 平均差, 差异像素占比)
    """
    g = np.load(golden_path + '.npy')
    if img.shape != g.shape:
        return False, None, None, None

    d = np.abs(img.astype(np.int16) - g.astype(np.int16))
    max_d  = int(d.max())
    mean_d = float(d.mean())
    bad    = float((d > atol).mean())

    ok = (bad < 0.01)          # 差异像素 < 1% 视为通过
    return ok, max_d, mean_d, bad


def fingerprint(img, rows=16):
    """只要一个"指纹"时用它：取画面底部若干行，抗噪且敏感"""
    return hash(img[-rows:, :, :].tobytes())
```

### Step 3：典型用法 —— 改完算法后测一遍

```python
img = grab_snapshot(buf0, v0)          # 见 ../pynq-dma-cache/SKILL.md
ok, mx, mn, bad = compare_golden(img, "./golden/frame_after_gray")
print("通过" if ok else "不通过", "最大差", mx, "平均差", round(mn, 3), "异常像素占比", round(bad*100, 2), "%")
```

## 已验证效果

本项目上用于：
- 抓帧后确认"画面还是原来那张"（改动没有破坏链路）
- 用**底部若干行做指纹**来判断"这一帧有没有变"（比整幅指纹更敏感、更抗噪）

---

## 来源（从哪些失败或观察中总结得出）

1. **大模型一开始想让需求方手工核对报告与画面** ⇒ 改为脚本比对。**机械比对永远优于人眼判断**。
2. **指纹粒度踩过坑**：整幅指纹在多缓冲环形搬运下会**饱和**（每个采样都在变），后来改成"只取底部十几行" —— 详见 `设计报告第 6 章`。
