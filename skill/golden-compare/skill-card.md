# Skill card: golden-compare

- **Name**: `golden-compare`
- **Description**: 需要证明"PL 算出来的结果是对的"，或改动算法后要逐值比对时使用。本技能只做比对方法与判据，不负责生成黄金模型本身。
- **Scope**: 通用。
- **已验证效果**: 把"看起来对"变成"逐字节相等"，边界拍错位、少算一个像素这类只在仿真里可见的错能被抓到。
- **来源**: 多次流水线改动后，屏幕上看不出差别，靠黄金参考比对才发现每帧差 ±1 个命中。
