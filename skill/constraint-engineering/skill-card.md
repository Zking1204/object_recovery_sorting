# Skill card: constraint-engineering

- **Name**: `constraint-engineering`
- **Description**: 要和 AI 协作完成一件多步骤工程任务，需要把约束条件写清楚、减少返工时使用。
- **Scope**: 通用。
- **已验证效果**: 8 条有效约束与 3 条反模式，能显著减少返工与误解。
- **来源**: 同一类返工被反复触发后，把"怎么说才有效"固化成模板，并验证过按模板描述的任务一次通过率明显更高。
