# Skill card: util-timing-collect

- **Name**: `util-timing-collect`
- **Description**: 综合实现完成后需要资源占用、时钟频率、关键路径数据，并要生成可与基线对比的报告时使用。
- **Scope**: 通用。
- **已验证效果**: 一条命令从实现报告里抽出 LUT / FF / BRAM / DSP 与 WNS / WHS / TNS，直接产出对比表。
- **来源**: 需要交"优化前后对比"时才发现没留数据，只能重跑综合，教训是每个改动都要当场记下资源与时序。
