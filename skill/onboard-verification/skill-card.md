# Skill card: onboard-verification

- **Name**: `onboard-verification`
- **Description**: 工程已经出位流，需要在板上按序验证，并要说清"每步成功长什么样、失败往哪查"时使用。
- **Scope**: 通用。
- **已验证效果**: 上板步骤有序、每步有判据、失败有分流；重跑时不会漏掉必须重跑的依赖步骤。
- **来源**: 多次上板因顺序错、重跑时漏掉依赖脚本，出现"刚才还好、现在不行"的假故障。
