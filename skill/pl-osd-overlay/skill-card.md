# Skill card: pl-osd-overlay

- **Name**: `pl-osd-overlay`
- **Description**: 要在 PL 里往实时视频流叠加图形或文字，并要求不闪烁、不打断视频通路时使用。
- **Scope**: 通用。
- **已验证效果**: 把叠加放在显示通路（帧缓冲读出之后、时序生成之前）实现零闪，且不占采集与识别带宽。
- **来源**: 早期把叠加做在采集侧，导致叠加闪烁并与识别争抢带宽，改到显示通路后两个问题同时消失。
